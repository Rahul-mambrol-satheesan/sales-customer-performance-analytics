# Data Source

This repository uses a **synthetic dataset generated specifically for this portfolio project**.

It does not contain real customer information and does not claim to represent any real company.

The synthetic data is intentionally designed to resemble a retail/e-commerce analytics environment with:
- customer master data
- product master data
- order transactions
- sales channels
- regions
- payment methods
- realistic business metrics
- intentionally introduced data-quality issues

Because the dataset is generated locally, the repository is self-contained and does not depend on a third-party download link.
