# Interview Preparation

Be able to explain the project in 60–90 seconds:

> I built an end-to-end Sales and Customer Performance Analytics solution using Python, MySQL and Power BI. I started with raw customer, product and order data, performed data-quality checks for duplicates, missing IDs, invalid quantities and discounts, then cleaned and transformed the data using Python. I loaded the validated data into a relational SQL model and used joins, CTEs and window functions to calculate KPIs such as revenue, profit, margin, AOV, customer rankings and month-over-month growth. Finally, I built a Power BI dashboard for executive, product and customer performance analysis.

## Questions to prepare for

1. Why did you use a relational model?
2. Why did you perform data-quality checks before analysis?
3. How did you handle duplicate orders?
4. How did you calculate profit?
5. How did you calculate month-over-month growth?
6. Why use a CTE?
7. Where did you use window functions?
8. How did you identify high-value customers?
9. How would you automate this pipeline?
10. How would you schedule the ETL process?
11. What would you do if sales and finance numbers did not reconcile?
12. How would you improve Power BI performance for millions of rows?
13. How would you communicate an unexpected decline in revenue to a stakeholder?
14. What additional data would you request from the business?
15. What limitations exist in this analysis?

Important: Do not memorize answers. Understand the logic and be able to explain each decision.
